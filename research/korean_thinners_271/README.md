# 국내 시판 신나 271건 연구 파이프라인 (삼화·노루)

**2026-10-23 연구 스냅샷 · 출처: 사용자가 수집한 제조사 MSDS · 검증 전 자료**

## 범위와 논문 가설
- 삼화 87, 노루 184, 합계 **271개 PDF 문서**. **271개 독립 제품**, 국내 시장 대표표본 또는 판매량 자료를 뜻하지 않는다.
- MSDS 제1항 용도/제품명으로 **14개 잠정 제품군** 분류, 제3항 화학물질 1,462행/고유 CAS 62종.
- 용도명칭 불명 86건, 구조 불명 복합물/혼합이성질체 포함 PDF 217건, 분자모델 예비 후보 46건, 기존 7종 물성표만으로 라울 예비 계산이 가능한 문서 6건.
- 동명 31그룹(63건)은 **중복 또는 개정판 검토 대상**이며 임의 삭제하지 않는다.
- MSDS는 `액상 조성 범위`를 주며 **제품의 실제 정확한 배합비는 제공하지 않는다**. 비공개 성분의 존재도 배제할 수 없다.

## 작업 단계
1. `data/제품목록_271.csv`, `data/성분별함량_1462.csv` 원문 출처와 추출 신뢰도 점검.
2. `data/제품271건_용도재분류.csv`와 `data/원본PDF_제1항_추가확인.csv`를 대조해 제품군을 확정하고 동명·개정 문서를 분리.
3. 구조 불명 CAS를 임의의 단일 SMILES로 치환하지 않고, `data/모델입력_차단성분.csv`와 `data/물성보완_62CAS.csv`에 필요한 확인 사항을 기록.
4. **25°C Raoult 기준모델**: 가능한 함량 조성을 생성하여 `x_i = (w_i/M_i)/Σ(w_j/M_j)`, `p_i=x_i P_i^sat`, `y_i=p_i/Σp_j` 계산. 기초 파일: 저장소 루트 `thinner_vle_reference_25C.csv`.
5. 실제 **UNIFAC, 2026 다성분 HANNA** 설치와 예측값·검증근거가 확보되면 동일한 조성 시나리오를 모델별로 비교. HANNA 실패 시 **Raoult 값으로 대체하지 않는다.**
6. 검증된 국내 고용노동부 **최신 TWA** 및 도료 물성/호환성 자료로 동일 사용목적군의 제품군 간 유해성 지표와 혼합비 최적화 가능성 평가.
7. 독립적인 VLE/헤드스페이스 실측 또는 질량감소 실험 검증 후 해석 강화.

## 사용법
저장소 루트에서 실행:
```powershell
python research/korean_thinners_271/src/validate_271.py
python research/korean_thinners_271/src/run_raoult_271.py --samples 2000
```
위 계산은 Python 표준 라이브러리만 사용. 연구환경 `chemprop`의 설치를 요구하지 않는다.

*출력은 기본적으로 `research/korean_thinners_271/output/` 아래 생성되며, .gitignore로 추적하지 않는다.*

## 모델 통합 범위
- **기존 v1의 `screen_korean_paint_thinners.py`는 정확한 조성/국내 TWA를 요구하는 별도 엄격 선별 도구로 보존**한다.
- 본 프로젝트의 함량 범위 분석은 단일값으로 조성을 조작하지 않는다.
- 2026 다성분 HANNA는 모델 코드와 체크포인트를 로컬에 구성한 뒤 어댑터로 연결할 후속 단계. 이 커밋은 학습된 HANNA 가중치를 포함하지 않는다.
- 증기발생 *잠재성* (평형증기압) ≠ 시간당 증발률 ≠ 작업장 공기농도 ≠ 법적 노출기준 초과판정.
- **최적 배합비/대체제품 권고/최고 위험 제품군은 현재 판정하지 않았다.**

## 데이터 출처 및 검토
- 전체 원본 PDF는 사용자 로컬에 보관. 공개 GitHub에는 재사용 가능한 정제 CSV, PDF 파일명과 SHA-256 추적정보만 포함.
- `data/라울_6건_요약.csv`는 과거 파일의 **예비 계산 결과**이며 AI 예측이나 실험 측정값이 아니다.
- `data/모델검수_가이드.md`의 MSDS 용도 불일치 사례를 주의.
- 구형 ChemExpo/EPA 연구 데이터는 국내 실제 판매제품의 근거로 인용하지 않는다.

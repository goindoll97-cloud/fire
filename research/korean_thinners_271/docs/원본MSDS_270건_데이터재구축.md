# 국내 시판 신나 MSDS 원본 기반 연구 데이터베이스 v1

## 이번에 실제 확인한 자료

- 노루 `노루_신나(1).zip`: **183개 PDF**.
- 삼화 `삼화_신나(1).zip`: **87개 PDF**.
- 두 ZIP의 순수 PDF 합계 **270건**. 기존 저장소의 `271`건 가운데 차이 1건은 `NR007`로, 파일명에 `신나무`를 포함한 **수성페인트 검색 오탐**이다. 기존 저장소의 271개 PDF 원본 해시 가운데 이번 ZIP의 270개 해시가 모두 일치한다.
- 270건 모두 제3항 성분 표가 추출되었고, 기존 자료에서 비신나 1건의 성분 8개를 제외한 **1,454개 CAS-문서 단위 성분기록**과 **54개 고유 CAS**를 식별했다.
- 원문 PDF를 다시 점검하면서 `SW058`의 다음 페이지에 이어진 제3항 1행(PGMEA)이 확인되어 누락 없이 반영했다.
- 자동 인식된 성분별 함량 범위는 1,454행 모두 **숫자 범위로 파싱**되었다. 이는 **사람이 숫자를 모두 검수했다는 뜻이 아니다**. 각 행에는 원본 SHA-256, 쪽수(잠정), 검수상태와 로컬 보관용 원문 근거가 기록되어 있다.
- 표기된 성분의 범위 내에서 합계 100%가 가능한 문서 267건, 기재한 최저 함량의 합계부터 100%를 넘는 **원문 재검토 대상 3건**이다. 이 3건을 자동 정규화하지 않는다.
- 미동정 복합물·혼합 이성질체 포함 문서 216건(아직 단일분자 HANNA 직접 입력 불가), 성분명이 단일 순물질 후보이고 함량범위가 수학적으로 유효한 문서 46건(모두 수동 동정·물성 출처 검증 필요), 기존 7종 *파일럿* 물성표만으로 계산 가능한 문서 6건.
- 동명 검토 63행(31개 동명 그룹)으로, **중복 PDF를 독립 상품으로 간주하지 않는다**.

## 연구 목표와 연결되는 데이터 구조

1. **MSDS 제품·문서 레지스트리:** 문서 SHA-256, 브랜드, 파일명, MSDS 번호 잠정, 용도 태그 잠정, 개정본 검토. `문서원본.csv`, `동명제품_중복개정_검토.csv`.
2. **성분·함량 레지스트리:** 문서키, CAS, MSDS 하한·상한, 범위 인식 상태, 혼합물/이성질체 차단, 페이지. `성분근거.csv` 및 로컬 전용 `원문근거_로컬전용.csv`.
3. **화학물질 속성·출처 관리:** 54개 CAS의 추출 빈도, 물성 검증 전용 필드, 데이터 획득 우선순위. `CAS_54종_물성보완_우선순위및승인서식.csv`. 7개 파일럿 물성은 기존 값이 있어도 **공식 검증으로 승격되지 않는다**.
4. **모델 적용 가능성 감사:** 원문 함량 범위, CAS 동정, 복합물/UVCB, 물성 검증 상태에 따라 자동 차단/수동 검토. `MSDS_270_모델적용성_평가.csv`.
5. **동일 용도 비교 및 최적화:** 용도 분류·개정본 검토·공정 호환성 및 최신 국내 TWA/출처 인증 후에만 유해성 잠재지표·상대비교에 연결. 기존 `screen_same_use_271.py`와 `optimize_verified_blend.py` 안전 검증 단계를 유지.

## 로컬 실행 — 원본 PDF는 GitHub에 올리지 않음

저장소 루트가 `D:\fire2`인 환경에서 노루/삼화 ZIP 원본을 각자 관리하는 로컬 경로에 저장하고 실행한다.

```powershell
cd D:\fire2
python -m pip install pymupdf

$source = 'D:\fire2\research\korean_thinners_271\data\source_rebuild_20261023'
$local = 'D:\fire2\research\korean_thinners_271\output\source_db_20261023'

python research/korean_thinners_271/src/build_msds_registry.py `
    --noru-zip 'D:\MSDS\노루_신나(1).zip' `
    --samhwa-zip 'D:\MSDS\삼화_신나(1).zip' `
    --legacy-index research/korean_thinners_271/data/제품목록_271.csv `
    --output $local

python research/korean_thinners_271/src/audit_research_readiness.py `
    --source $local `
    --output "$local\audit"

python -m unittest discover -s research/korean_thinners_271/src -p 'test_*.py' -v
```

원본 ZIP을 `D:\MSDS` 이외 폴더에 보관했다면 인수 두 개의 경로만 변경한다. 자동생성 결과는 저장소 추적 제외된 `output/` 아래에 보관한다. 참고용 Github `data/source_rebuild_20261023/` 자료는 **원본 SHA-256과 공개 가능한 정제 수치만** 포함하며 원본 PDF와 페이지별 원문 발췌는 포함하지 않는다.

### 자료 승인 규칙

- `CAS_54종_물성보완_우선순위및승인서식.csv`는 **전부 미승인 상태**로 생성한다. SMILES, MW, 온도 조건이 명시된 포화증기압과 원문 출처가 검증되기 전에는 결측치를 임의 보간하거나 '승인'으로 변경하지 않는다.
- `1330-20-7`, `64742-95-6`, `64742-94-5`, `25551-13-7` 같은 혼합 자일렌·나프타·이성질체 혼합물에는 **단일 SMILES를 배정하지 않는다**. 별도의 혼합물 동정/TDS 검증 과정이 필요하다.
- 함량의 수치적 범위는 실제 제조사 비밀 배합을 복원하지 않으며, 성분이 추가로 비공개되었을 수 있다.
- 한국 TWA의 과거 스냅샷 또는 NIOSH OEL을 최신 국내 TWA로 오인하지 않는다.
- 46개 단일 순물질 조합 후보를 **46개 완성된 예측**이라 부르지 않는다. 현재 HANNA 예비계산 가능 6건과 구분한다.
- 비이상성 모델 간 차이만으로 기액평형 정확도, 증발속도, 작업장 노출량 또는 더 안전한 제품 구매 추천을 주장하지 않는다.

## 데이터를 늘리기 위한 우선순위

단일 성분을 추가하면 다른 모든 CAS가 기존 7종 안에 있고 복합물/UVCB가 없는 문서에 한해 추가 가능 문서를 계산했다. 물성·SMILES와 출처를 검증한 **MEK (CAS 78-93-3)** 하나를 보완하면 **7개 문서가 추가로 숫자 예비계산 후보**가 될 수 있다. PGMEA, n-부탄올 등 다른 단일 CAS를 먼저 확인해야 하는 문서도 있다. 이는 검증 완료의 수치가 아니라 **자료확보 우선순위**이다. 실제 논문에서는 CAS 54종 물성표 확대와 제품군·실측 VLE/헤드스페이스 검증을 병행한다.

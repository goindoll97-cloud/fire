# 논문 가치 검증 실험: 반복 표본추출·비이상성·독립 VLE 검증

이 문서는 **실험 계획과 재현 실행법**을 정의합니다. 프로그램이 실행되더라도 **논문 게재 가능성, 모델 정확도, 유해성 감소, 실제 배합 최적화가 입증된 것은 아닙니다.**

## 연구 질문과 귀무적 해석 대안

1. **Q1: 비이상성 보정이 신나 혼합물의 증기상 예측을 얼마나 바꾸는가?** 동일한 가능한 MSDS 조성에서 `p_i = x_i γ_i P_i^sat`와 `p_i = x_i P_i^sat`를 쌍으로 계산하고 총압력 비 및 기상 조성을 비교합니다. 서로 다른 모형 간 불일치는 **정확도 개선의 증거가 아닙니다**.
2. **Q2: 발견한 차이가 조성 표본추출 방식·시드에 민감한가?** 원래의 `legacy` 조건부 거절표본추출과 `gibbs` 유계 단체(pairwise conditional uniform) 표본추출, 3개 이상 난수시드로 민감도를 비교합니다. Gibbs는 유계 단체의 균일분포를 불변분포로 가지지만, **유한 길이 사슬의 수렴·독립성은 보장되지 않습니다**. 시드 간 차이와 근접 동률을 함께 보고합니다.
3. **Q3: 우세한 증기상 성분이 달라지는가?** 단순 argmax 전환과 각 모형 우세성분 1·2위 기상몰분율 차이가 `0.01` 미만(1%p)이어서 결론이 민감한 경우를 구분합니다. 전환율은 가상 시나리오 표본의 기술량이며 제조사 제품의 발생확률이 아닙니다.
4. **Q4: HANNA가 관측 VLE에 더 가까운가?** 출처·온도·물성 검증된 **독립 실측** 버블압력이 제공된 후에만 MAE/RMSE를 구합니다. 연구용 MSDS 조성 시나리오에서 HANNA와 Raoult를 비교하는 것으로 Q4를 답할 수 없습니다.
5. **Q5: 같은 용도의 저유해성 대체 및 혼합비 최적화가 타당한가?** 최신 국내 TWA, 효과별 가산성, 동일 수지/공정, 노출·인화·성능·비용·호환성 및 독립 품질시험 전에는 **보류**합니다. 비교 프로그램의 미승인 순위 0건은 정상입니다.

## Windows 로컬 전체 실험 실행

저장소 경로가 `D:\fire2`, 외부 HANNA 체크포인트가 `D:\fire2\HANNA`에 있는 경우:

```powershell
conda activate chemprop
cd D:\fire2
git pull --ff-only origin main
$env:HANNA_HOME = 'D:\fire2\HANNA'

# 데이터 원본 구조 우선 검사
python research/korean_thinners_271/src/validate_271.py
python -m unittest discover -s research/korean_thinners_271/src -p 'test_*.py' -v

# 전체 실험: 2개 조성추출법 x 3개 난수시드 x 6문서 x 200조성 = 7,200 시나리오
python research/korean_thinners_271/src/paper_experiment_271.py run `
  --root 'D:\fire2\research\korean_thinners_271\output\paper_full' `
  --samplers legacy gibbs --seeds 20261023 20261024 20261025 `
  --samples 200 --batch-size 8 --burn-in 300 --thin 12

# matplotlib가 있는 경우 (없으면 기존 결과 표/보고서에는 영향 없음)
python research/korean_thinners_271/src/plot_paper_experiment_271.py `
  --reports 'D:\fire2\research\korean_thinners_271\output\paper_full\reports'
```

중단된 경우 **동일 명령으로 재실행**하면 정상 완료되었고 입력 SHA/시드/표본수가 같은 실행은 재사용하며, 불완전하거나 설정이 다른 폴더는 자동 덮어쓰지 않고 실패합니다. `--samples` 또는 시드/모델 조건이 바뀌면 **새 `--root` 폴더**를 사용하세요. 전체 실행은 로컬 HANNA 모델의 추론 시간이 걸립니다. 모델 체크포인트는 GitHub Actions와 이 저장소에 포함하지 않습니다.

계산 결과만 다시 요약할 경우 (HANNA 로딩 불필요):

```powershell
python research/korean_thinners_271/src/paper_experiment_271.py summarize `
  --root 'D:\fire2\research\korean_thinners_271\output\paper_full'
```

## 생성 결과

- `output/paper_full/runs/legacy_seed_*/` 및 `gibbs_seed_*/`: 시나리오·성분별 HANNA/Raoult 계산 원자료, 실행 메타데이터(SHA-256).
- `output/paper_full/reports/paper_반복별_통계.csv`: 문서·표본추출법·난수시드별 총압력비, 분위수, 우세성분 전환 및 동률 민감도.
- `paper_제품별_안정성.csv`: 시드별 중앙값의 범위 및 전환율 안정성.
- `paper_표본추출_민감도.csv`: 두 표본추출법 사이 결과 차이.
- `paper_논문가치_판정.md`, `paper_실험재현정보.json`: 해석 가능 범위·해석 제한·입력 SHA-256·실험 조건.
- `Figure_1_sampling_sensitivity.png`: 선택적 학술용 모형 간 차이 그림.

분석 모듈은 성분 CAS 완비, 질량합계, 몰분율합계, `ln γ`, 각 성분 Raoult/HANNA 분압과 총압력, 기상몰분율, 유한값을 **전수 검사**하고 오류 또는 입력 SHA 불일치 시 즉시 중단합니다. 자료 누락이 있는 실행들을 조용히 합쳐서 통계를 내지 않습니다.

**200개의 가상 조성은 독립 제품 200개가 아니며, 반복 시드·Gibbs 사슬을 합쳐 만든 p-값이나 신뢰구간으로 해석하지 않습니다.** 동일 제품·유사 MSDS 개정판일 수 있는 문서들의 외적 타당성도 자동 보장하지 않습니다.

## 독립 실측 VLE 검증: 근거 파일 없으면 실행하지 않음

25°C 실측 버블압력 원문과 순물질 VP 출처 대조를 수작업 검증한 뒤 수행합니다. 아래 서식은 **모두 빈 값**으로 생성되며 예시 실측치를 만들지 않습니다.

```powershell
python research/korean_thinners_271/src/validate_external_vle_271.py `
  --write-templates 'D:\fire2\research\korean_thinners_271\output\external_vle_evidence'
```

원문 문헌과 대조하여 `독립VLE_실측입력_서식.csv`에 `reference_id`, `source_url_or_doi`, `verification_status=승인`, `temperature_K=298.15`, `CAS_JSON`(예: `["141-78-6","67-64-1"]`), `liquid_x_JSON`(예: `[0.5,0.5]`), `observed_total_pressure_kPa`를 입력합니다. 여기의 숫자·SMILES는 **서식 설명일 뿐 실측 자료가 아닙니다**. `순물질_포화증기압_출처승인_서식.csv`에서 사용되는 **모든 CAS**에 대해 25°C VP, DOI/URL, 정확한 수치, 승인 상태를 검증해야 합니다. 기존 `thinner_vle_reference_25C.csv`와 VP가 일치하지 않으면 실행을 거부합니다.

```powershell
python research/korean_thinners_271/src/validate_external_vle_271.py `
  --measurements 'D:\fire2\research\korean_thinners_271\output\external_vle_evidence\독립VLE_실측입력_서식.csv' `
  --property-evidence 'D:\fire2\research\korean_thinners_271\output\external_vle_evidence\순물질_포화증기압_출처승인_서식.csv' `
  --output 'D:\fire2\research\korean_thinners_271\output\external_vle_validated'
```

실측자료와 참고물성의 출처가 타당한지는 프로그램이 자동으로 검증할 수 없으므로 **인증이 아니라 사람이 수행하는 근거 확인**입니다. 단일 문헌에서 얻은 조성 포인트들을 서로 독립적인 실험으로 가정해서 확률적 신뢰구간을 만들지 않습니다.

## 논문 작성 판단 기준

- **가능한 주장**: 특정 MSDS 시나리오에서 HANNA와 Raoult의 계산 차이, 계산 입력과 출력의 재현성, 조성 생성 민감도.
- **추가 검증 후 가능한 주장**: 외부 VLE/헤드스페이스 자료와 대조한 모델 정확도, 온도 및 혼합물 계열 외삽 성능.
- **추가 산업안전 증거가 필요한 주장**: 실제 노출농도의 감소, 법적 TWA 초과 여부, 동일 용도 대체품의 안전성, 새 혼합비의 품질·안전·최적성.

입력 MSDS의 271건은 **PDF 문서 수**이고 중복·개정본이 포함되며, 모델 입력구조 후보 46건 전체가 즉시 예측 가능한 것은 아닙니다. 신규 물성 확보 시 실험 대상을 점진적으로 늘리되, 불명확한 혼합 자일렌·나프타를 임의 단일 SMILES로 대체하지 마세요.

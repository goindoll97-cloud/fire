# 배합비 최적화의 실행 전 확인조건

## 최적화 목적
특정 수지/도장공정에서 허용되는 혼합비 `w_i`를 찾고, 검증된 AI 활동도계수 예측 `gamma_i(w,T)`를 이용해
`p_i = x_i * gamma_i * P_i^sat(T)`를 계산한다. 목적은 예를 들어 (1) 국내 TWA를 이용한
상대적 분압 지표와 (2) 총 평형증기압을 낮추면서 도료의 기능 제약을 충족하는 비지배(Pareto) 해를 찾는 것이다.

## 반드시 준비할 데이터
1. **각 CAS의 단일 분자 동정**, SMILES, 온도별 포화증기압, 분자량. 혼합자일렌/나프타는 성분별 동정 전 제외.
2. **현행 한국 고용노동부 TWA**, 단위와 적용대상, CAS 매칭, 법령 시점. NIOSH 값을 국내 기준 대용으로 사용하지 않는다.
3. 대상 도료의 **정확한 수지 계열과 희석제 호환성**, 제조사 TDS 또는 독립 실측.
4. 허용 농도, 각 성분의 사용 가능 여부와 상한, 원료의 인화점, 용해도 매개변수(HSP), 건조속도, 비용 등.
5. 조성 `sum(w_i)=1`과 성능 제약을 동시에 만족하는 탐색영역.
6. 2026 다성분 HANNA **모델 가중치·작동 검증·적용 가능 영역** 및 독립 기액평형 실측 비교.

## 해석 제한
- 함량 범위 내 탐색은 제조사의 실제 배합비 복원이 아니다.
- 최적화에서 사용하는 예측모델은 새 조성 분포에도 적용 가능한지 검증해야 한다.
- 모든 모델과 모든 조성이 실제 작업장의 증발속도·노출농도를 직접 예측하지 않는다.
- 필요한 조건이 확보되기 전에는 코드를 실행해 **'저독성 최적제품'이라는 결과를 만들지 않는다.**
- 데이터 확보 후 `NSGA-II` 또는 제약된 Bayesian optimization/다목적 진화탐색을 적용한다.

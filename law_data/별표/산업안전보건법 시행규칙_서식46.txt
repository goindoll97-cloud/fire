   1. 제조공장:                                                                         
  ‘000시 00구 00’에서 생산하는 제품에 한함                                            
                                                                                        
                                                                                        
                                                                                        
   2. 제품개요                                                                          
                                                                                        
      작성 예) 에어리시버 탱크                                                          
                                                                                        
                                                                                        
                                                                                        
   3. 인증범위:　본 인증서는 아래의 형식번호에 한하여 유효함                            
                                                                                        
       작성 예) HAT - a 0 0 b - c d                                                     
                      a = 1, 5                                                          
                      b = 0, 1, 2, 3, 4                                                 
                      c = W, E                                                          
                      d =  2, S                                                         
                                                                                        
                                                                                        
                                                                                        
   4. 안전한 사용을 위한 조건                                                           
                                                                                        
    - 작성 예) 주위온도 -20~60℃의 범위내에 설치되어야 함.

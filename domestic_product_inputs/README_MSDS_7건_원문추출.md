# 사용자 제공 국내 도료 희석제 MSDS 7건: 원문 성분정보 데이터

이 자료는 2026-10-23에 사용자가 제공한 **제조사/공급사 MSDS PDF 7개**의 3항 '구성성분의 명칭 및 함유량'을 수동 대조·전사한 것입니다. PDF 원본 자체는 공개 GitHub에 업로드하지 않았습니다. 원본 문서 SHA-256, 정확한 파일명, MSDS 개정일, 원문 함량 표현, 성분 CAS, PDF 쪽수를 보존했습니다. 제조사 사이트에서의 현행본 여부·현재 판매 여부는 별도로 확인해야 합니다.

## 파일

- `domestic_product_inputs/korean_msds_products_7.csv`: 제품별 식별자, 문서 이력, 공개 성분수, 범위 합계, 제약 및 미검증 사항.
- `domestic_product_inputs/korean_msds_components_39.csv`: 원문 제3항의 39개 성분 행, 원문 표현, wt% 하한·상한, 물질 유형, 원본 PDF 페이지.
- `audit_korean_msds_data.py`: 두 CSV의 CAS 중복/제품 일치/함량 범위/합계/물질 유형 검증. 옵션 `--pdf-dir` 지정 시 원본 PDF의 SHA256을 추가 검증.
- `test_audit_korean_msds_data.py`: 기본 자동검사 6개; 원본 PDF를 로컬에 두지 않으면 PDF 검증만 skip.

## 실행

```powershell
cd D:\fire
python -m unittest -v test_audit_korean_msds_data.py
python audit_korean_msds_data.py
# 원본 PDF 7개가 D:\fire\local_msds_pdfs 에 있을 때만:
python audit_korean_msds_data.py --pdf-dir D:\fire\local_msds_pdfs
```

## 연구 해석에서 반드시 지킬 원칙

1. **7개 제품 모두 MSDS가 단일한 정확한 배합비를 제공하지 않습니다.** 합계가 100%인 특정 값은 제조사가 제공한 실제 배합비가 아닙니다. 하한합 ≤100≤상한합은 '기재 성분이 전체를 구성한다'는 가정 하에 수학적으로 가능한 조성이 존재할 수 있다는 뜻일 뿐입니다.
2. 2026년 최신 문서 두 건: KCC 락카희석제030(2026-07-31) 및 노루 DR-170L(2026-09-10). **노루 DR-170(골드)와 DR-170L은 별개 제품 및 별개 MSDS 번호**입니다.
3. CAS 1330-20-7은 혼합 자일렌 이성질체이며 개별 이성질체 분율 없이는 단일 SMILES로 HANNA를 돌릴 수 없습니다. KCC 에나멜신나의 나프타 CAS 3개는 복합석유계 UVCB이므로 단일화합물처럼 모델링할 수 없습니다.
4. KCC 락카신나 MSDS의 메탄올 `4 ± 5%`는 수학적 하한 -1%가 발생합니다. CSV의 물리적 하한은 0%로 제한하고 **원문은 그대로 보존**했습니다. 이 값의 진의는 제조사 확인 대상입니다.
5. MSDS 3항에 미기재 물질이 없다는 보장이 없으므로 이 자료만으로 실제 전체 조성, 미기재 성분의 존재, MSDS 기재 의무 위반을 판정할 수 없습니다.
6. 기존 `screen_korean_paint_thinners.py`의 **단일 배합 계산은 이 범위형 CSV의 모든 제품을 보류**해야 합니다. 아직 HANNA 결과나 제품 순위를 생성하지 않았습니다. 향후 범위 제약 샘플링, 물성 DB 확장 및 모델 검증을 분리해서 수행해야 합니다.
7. 원본이 유통제품의 최신본인지 확인하지 못한 문서에 대해 2026년 현재 계속 판매된다는 주장을 하지 않습니다. 제품 용도와 성능·도료 호환성도 검증 전입니다. 가격 자료는 본 분석의 필수값이 아닙니다.

## 권장 후속 작업

먼저 분자 식별이 쉬운 KCC 락카신나(6성분)와 삼화 LA신나2000(4성분)을 대상으로 누락 물성(증기압·SMILES·분자량) 확충을 검토합니다. 나머지는 자일렌 이성질체 조성 또는 나프타 분획 특성을 별도 확인해야 합니다. 다음으로 '**기재 성분이 전체를 구성한다**'는 **명시적 조건부 시나리오** 안에서만 함량 범위를 샘플링하고 HANNA/UNIFAC 비교를 수행합니다. 해당 결과는 실제 제품 제조배합이나 작업환경 노출농도가 아닙니다.
